В программе производится сравнение словарного состава параллельных текстов на русском и турецком языках. Выполняются следующие задачи:

1. Токенизация текста: Тексты делятся на токены (слова) с использованием библиотеки NLTK. Очищаются от знаков препинания и неалфавитных символов.
   
2. Лемматизация и определение частей речи: Для русского языка используется библиотека pymorphy3, для турецкого — zeyrek. Программа определяет леммы и части речи для каждого слова.

3. Частотный анализ: Программа создает частотные словари с помощью collections.Counter, подсчитывая количество лемм в текстах.

4. Коэффициент лексического богатства: Рассчитывается отношение уникальных лемм к общему количеству лемм в тексте.

5. Частотный анализ по частям речи: Программа выделяет и подсчитывает частоту употребления существительных, глаголов и прилагательных в текстах.

6. Визуализация: Используя matplotlib и pandas, программа строит графики для наиболее частотных слов и частей речи.

Программа требует установки следующих библиотек:
- pymorphy3
- zeyrek
- matplotlib
- pandas
- nltk
- re

Инструкция по использованию:

1. Убедится, что установлены все библиотеки, перечисленные выше.
2. При запуске программы необходимо вручную ввести названия файлов с текстами на русском и турецком языках.
3. Для тестирования ввести названия "test1_rus.txt" , "test1_tr.txt", "test2_rus.txt" , "test2_tr.txt", "test3_rus.txt" , "test3_tr.txt"
(1 - тест с повторяющимся словом в разных формах, 2 - текст с низким лексическим богатством, 3 - обычный тест)
Для тестирования на произведении Федора Достоевского "Преступление и наказание" введите названия "dostoev_rus" и "dostoev_tr"
4. Будут выведены в одной таблице диаграммы с самыми частыми словами в русском и турецком языках в общем и в разных частях речи 
(существительное, прилагательное, глагол), а также частоты всех частей речи. 
5. В файл "results.txt" будут распечатаны: объем частотного словаря, частотные словари, коэффициент лексического богатства, 
количество уникальных существительных, прилагательных, глаголов
6. Прикладная задача: для составления частотных словарей, запустите программу application.py, словари будут сохранены в файлах
frequency_russian.txt и frequency_turkish.txt
